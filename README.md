# Bhutan Tarema Tours

PHP website for Bhutan Tarema Tours.

## Run locally

Install PHP, then run `php -S localhost:8000` from this folder. Open http://localhost:8000. If the local PHP runtime is installed, Windows users can run `./start-server.ps1`.

## Database configuration

Set the `DB_PASSWORD` environment variable for database-backed pages. Existing local installations can use the ignored `local-secrets.php` file. Credentials, the local PHP runtime, server logs, and the password-generation helper are excluded from Git.
